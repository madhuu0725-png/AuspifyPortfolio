## 💻 Running Locally

```bash

```
Visit: `http://localhost:3000`

### Option 2: Node.js / NPX
```bash
npx serve . -l 3000
```

## 🚀 Instant Deployment (Step 5)

### Deploying to GitHub Pages
1. Push to your repository:
   ```bash
   git init
   git add .
   git commit -m "Madhulatha Konka MERN Portfolio"
   git branch -M main
   git remote add origin https://github.com/madhuu0725-png/<repo-name>.git
   git push -u origin main
   ```
2. In GitHub repository **Settings** > **Pages** > Select `Deploy from branch: main / root`.

### Deploying to Vercel
```bash
npx vercel
```
Using the included zero-config `vercel.json`.
